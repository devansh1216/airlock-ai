Enforcement Glossary

ALLOW

Sends raw value to LLM. Used for public URLs or general references.

SANITIZE

Replaces value with local token <TYPE_1> and rehydrates after. Zero cloud retention.

BLOCK

Rejects request with 403 Forbidden. Recommended for AWS/API secret keys.

Cryptographic Privacy Vault

In-memory reversible surrogate token registry. Mapping tables are isolated strictly in local process memory and zeroized upon request completion.

Python Drop-in Wrapper

import requests

def ask_airlock(prompt: str) -> str:
    """Drop-in privacy proxy for cloud LLMs."""
    response = requests.post(
        "http://127.0.0.1:8000/api/v1/secure-chat",
        json={"prompt": prompt}
    )
    data = response.json()
    if not data.get("success"):
        raise RuntimeError(f"Airlock blocked: {data.get('message')}")
    # Return locally restored answer
    return data["final_response"]

# The cloud model receives only  and 
answer = ask_airlock("Contact Alice Cooper at alice@company.com")
print(answer)

FastAPI Server-Sent Events (SSE) Stream

const response = await fetch("http://127.0.0.1:8000/api/v1/secure-chat/stream", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ prompt: "My secret data..." })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  console.log(decoder.decode(value));
}
